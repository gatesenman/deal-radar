网络代理

在中国大陆访问 Google 新闻、Reddit 等境外站点通常需要代理。使用 Clash / v2rayN 并已开启「系统代理」时选「跟随系统」即可。

常用：

采集引擎（专业）

不同站点并行抓取；同一站点始终串行

限速，避免触发 Reddit / GitHub 等的限流（429）

连续失败 ≥2 次的渠道按 2ⁿ 倍刷新周期暂停（最长 6 小时），手动刷新不受影响

发送 ETag / If-Modified-Since，服务器返回 304 时直接复用，省流量更快

用隐藏浏览器渲染 Perplexity、x.ai、Midjourney、Canva 等动态页面（每次约 5–15 秒，最多同时 2 个）

链接规范化 + 标题相似度合并重复报道，卡片显示「N 个来源」

公共实例 rsshub.app 已限制访问；填写后可在渠道中使用「RSSHub 路由」协议

导入 / 导出

与 Feedly、Inoreader、Reeder 等 RSS 阅读器互通。导入到某个厂商：在厂商详情页点「导入 OPML」

包含厂商、渠道、聚合源、提醒规则和设置，可在另一台电脑上恢复

包含优惠（收藏 / 已领取 / 反馈）、视图、价格历史和配置。推送渠道密钥和 AI Key 不会写入备份，换电脑后需重新填写。
