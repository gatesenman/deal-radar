# 全网优惠雷达（Deal Radar）使用说明 · v2.5.0

中文 · [English](README.en.md)

一款 Windows 桌面应用：**实时监控 ChatGPT、Claude、Gemini、Cursor、DeepSeek 等 AI / 软件厂商的最新优惠**，包括免费试用、学生优惠、API 赠送额度、降价折扣、新用户优惠、黑五 / 双 11 限时活动、创业扶持计划，以及价格页的变动。每个厂商都有自己的多条信息渠道（官方博客、价格页、更新日志、状态公告、YouTube、GitHub 发布、社区论坛、Reddit），另外还有全网聚合源（Google/Bing 新闻、Hacker News、Reddit、V2EX、Slickdeals……）。发现新优惠时弹出桌面通知。实物商品（Apple、Nike 等）的打折监控是可选功能，默认关闭。

## 一、安装 / 运行

二选一：

- **安装版**：双击 `DealRadar-Setup-2.5.0-x64.exe`，按提示安装（可以自己选目录），装好后桌面和开始菜单会出现「全网优惠雷达」。
- **免安装版**：双击 `DealRadar-Portable-2.5.0-x64.exe` 直接运行，首次启动需要几秒解压。

> 应用没有数字签名，Windows SmartScreen 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。
> 从 v1.x 升级到 v2.0 时，收藏、设置、自建渠道都会保留；v2.0 新增的厂商（Meta、Figma、讯飞星火）默认关闭，被精简掉的冷门预置厂商若你启用过会转为自定义厂商保留。
> 从 v1.0 / v1.1 升级时，原有收藏和设置都会保留，首次打开会再显示一次欢迎页，用来选择 AI 厂商。之前监控的实物品牌会自动放进「实物优惠」。

## 二、快速上手

1. **首次启动**会弹出欢迎页：选好要监控的 AI 厂商（默认选中 14 家主流厂商）、要不要同时监控实物商品、用哪种网络方式，然后点「开始监控」。大约 20–60 秒后，「AI 优惠」里会出现真实优惠。
2. **AI 优惠列表**
   - 每条优惠都会标出类型：`免费试用`、`折扣降价`、`赠送额度`、`学生教育`、`创业扶持`、`限时活动`、`新套餐`、`价格页变动`。
   - 列表**默认只显示识别为优惠的内容**。勾选「含资讯」后，厂商渠道里的普通动态也会显示出来（新功能发布、状态公告、论坛帖子等），这些条目标为灰色「资讯」，不会弹通知。
   - 可以按厂商、优惠类型、国际 / 中文筛选，也可以只看未读；支持搜索（Ctrl+F）、卡片 / 表格两种视图、收藏、导出 CSV。
   - 单击条目查看详情，双击在浏览器中打开原文。
3. **厂商与渠道**（左侧菜单）
   - 用开关启用或停用厂商；用铃铛单独静音某个厂商的通知。
   - 点「＋ 添加厂商 / 关键词」可以添加预置之外的任意厂商，也可以输入任意关键词（如 `GPT-6`、`Claude Max`）。
   - 点厂商卡片（或「渠道」按钮）进入**厂商详情**，这里能看到该厂商每个渠道的状态（正常 / 失败及原因）、条目数和上次检测时间，下方是来自所有渠道的最新动态。
   - **添加 / 编辑 / 删除渠道**，有三种方式：
     - **RSS / Atom**：官方博客、更新日志、YouTube 频道（`https://www.youtube.com/feeds/videos.xml?channel_id=…`）、GitHub Releases（`…/releases.atom`）、Discourse 论坛（`…/latest.rss`）、自建 RSSHub 等。这类渠道的条目全部归属该厂商，识别为优惠的会提醒你。
     - **网页变化监控**：定时抓取网页，把正文和上次的快照对比，内容一有变化（例如价格调整、新增促销）就生成一条「价格页变动」动态，并附上新增 / 移除的内容片段。可以填 CSS 选择器（只比较页面的某一部分），或只关注含某些关键词的行，用来减少误报。首次检测只建立基线；点「快照」可以查看当前提取到的文字。
     - **搜索关键词**：用 Google 新闻搜索近 30 天的该关键词（例如 `Kimi 会员 优惠`）。
4. **聚合数据源**：Google / Bing 新闻、Hacker News、Reddit、V2EX 等会按每个厂商的关键词搜索。这类来源**必须同时满足**两个条件才收录：标题里出现了厂商名，且识别出优惠类型（提问帖、新闻汇总、「优惠已暂停 / 结束」这类标题会被排除）。
5. **实物商品（可选）**：在「设置 → 监控范围」或「厂商与渠道」底部开启，侧边栏会多出「实物优惠」，监控 Slickdeals、mydealz、IT之家等 29 个平台上 Apple、Nike 等品牌的打折信息（与 v1.1 相同）。
6. **后台监控**：点 × 后应用缩到系统托盘继续运行；右键托盘图标可以「立即刷新 / 暂停监控 / 退出」。

## 四、v2.0 专业功能

- **20 种采集协议**（「添加渠道」里选择，带说明和**▶ 测试预览**，不保存即可看到抓取结果）：
  - 订阅 / 通用：RSS / Atom / RDF、JSON Feed、JSON API（JSONPath + 字段映射）、HTML 列表（CSS 选择器）、网页变化监控、JS 渲染页（隐藏浏览器，可过人机验证等待页）、Sitemap 新页面、Google / Bing 新闻搜索、RSSHub（自定义实例地址）。
  - 平台：GitHub（Releases / Tags / Commits，Atom 或 REST API）、Hacker News（Algolia，可设最低分）、Reddit（版块 + 搜索）、Discourse 论坛、Telegram 公开频道（t.me/s）、Mastodon（账号 / 话题）、Bluesky、YouTube 频道、Product Hunt、App Store、Google Play。
  - 每个渠道的高级选项：独立刷新周期、超时、User-Agent、自定义请求头、是否走代理、包含 / 排除关键词、标题正则。
- **源健康**（左侧菜单）：总渠道数、成功率、平均耗时、缓存命中、异常数；按协议分布条（点击筛选）；每个渠道显示最近 40 次运行的成功率曲线、耗时、最后错误；「日志」查看逐次运行记录；「重测异常」一键重试失败渠道。
- **采集引擎**（设置）：并发数、同站点间隔、失败指数退避（2 次失败后逐步跳过，最长 6 小时）、ETag / If-Modified-Since 条件请求缓存（未变化返回 304，不重复下载）、JS 渲染开关、跨源去重开关。Reddit 等严格限流站点自动放慢。
- **跨源去重**：同一新闻被多家媒体报道时合并为一条，显示「N 个来源」，详情里列出全部来源链接。
- **重要度评分**（0–100）：综合优惠类型、是否官方渠道、来源数、热度、标题关键词；列表可按「重要度」排序，≥70 分高亮。
- **提醒规则**（左侧菜单）：按 厂商 + 优惠类型 + 关键词（含 / 不含）+ 最低重要度 → 桌面通知 / 提示音 / 卡片高亮色。默认规则：所有优惠通知；免费 / 赠送额度 / 学生优惠响铃并绿色高亮；价格变动响铃并粉色高亮。可「试运行」看现有数据会命中多少。
- **时间线视图**：按天分组，按时刻排列。
- **导入 / 导出**：OPML（与 Feedly、Inoreader 等阅读器互通，可导入到全局源或某个厂商）、完整配置 JSON（厂商、渠道、规则、设置）。
- **键盘快捷键**（按 `?` 查看）：`J / K` 或方向键上下移动，`Enter / O` 打开，`S` 收藏，`M` 已读 / 未读，`Shift+A` 全部已读，`V` 切换视图，`N` 含资讯开关，`1–7` 切换页面，`Ctrl+F` 搜索，`F5` 刷新，`Esc` 关闭。

## 五、v2.1 AI 辅助添加

- **AI 助手（设置 → AI 助手）**：任意 OpenAI 兼容接口。预置 DeepSeek、通义千问 / 阿里云百炼、Kimi、智谱、豆包 / 火山方舟、OpenAI，以及「自定义」（OpenRouter、本地 Ollama 等）。选服务商后自动填好接口地址和模型，填入 API Key 点「保存」，再点「测试连接」。
  - **Key 的安全**：用 Windows 系统安全存储（DPAPI，经 Electron safeStorage）加密后保存在本机；界面、日志、错误提示、导出的配置里都不会出现明文（只显示 `sk-…1234` 这样的提示）。系统不支持加密时，Key 只在本次运行中有效、不写入磁盘。
  - **不配置 AI 也能用**：发现流程全部有内置规则兜底；AI 只负责「锦上添花」（中英文别名、排除词、渠道归类、列表页的 CSS 选择器、理解自然语言）。
- **✨ AI 辅助添加厂商**（厂商与渠道 → ✨ AI 辅助添加）：输入名称（如 `Hugging Face`、`Mistral`、`Kimi`），应用会自己完成整个流程，并实时显示进度、可随时「停止」：
  1. 搜索官网与官方账号：Bing 网页结果 + Wikidata（官网、YouTube、GitHub、Bluesky、Mastodon、App Store、Google Play 等官方记录），DuckDuckGo 作为备用。不需要任何搜索 API。
  2. 确定官方域名：与名称无关的域名、仿冒 / 导流站、百科和媒体站会被排除；配置了 AI 时由 AI 在搜索结果中确认（AI 不能凭空给出搜索结果之外的域名）。
  3. 读取官网：`<link rel=alternate>` 声明的 RSS / Atom / JSON Feed、常见订阅路径（/feed、/rss.xml、/blog/rss.xml…）、sitemap.xml、价格页 / 学生 / 创业计划页、博客与更新日志页、Statuspage 状态 RSS、Discourse 论坛、GitHub 组织的热门仓库、YouTube 频道（@handle 自动解析成频道 ID）、Bluesky / Mastodon / Telegram，以及 App Store（开发者需与官网匹配）和 Google Play；另外自动加上中英文新闻搜索和 Hacker News。
  4. （可选）AI 归类：决定保留哪些、所属类别、中文名称，补全别名与排除词，并可建议最多 4 个官网页面（必须在官网域名下，否则丢弃）。
  5. 逐个实测：每个候选都用现有协议真实抓取一次；网页被拦截时自动改试 JS 渲染。
  然后显示**审核列表**：协议、地址 / 参数、实测结果（条数或行数，失败原因）、样例条目，可勾选 / 取消、修改名称别名排除词。实测失败、0 条、重复的订阅源默认不勾选。点「添加厂商和 N 个渠道」后立即保存并抓取一次。如果厂商已存在（含预置但未启用的），勾选的渠道会加到已有厂商下。
- **✨ AI 辅助添加渠道**（任意厂商 → 添加渠道 → 顶部「智能识别」）：
  - 粘贴网址：自动判断协议。RSS / Atom / JSON Feed 直接订阅；JSON 接口自动找条目数组和字段；网页先找订阅源，价格页用网页变化监控（自动选 `main` 等区域）；文章列表页推断 CSS 选择器（有 AI 时由 AI 生成并验证至少匹配 3 条）；正文由 JS 生成或有人机验证时改用 JS 渲染；GitHub、YouTube、Reddit、Bluesky、Telegram、App Store、Google Play、HN 链接直接用对应协议。
  - 一句话描述（如「Claude 的定价页改价提醒」）：有 AI 时由 AI 定位官方页面；没有 AI 时根据该厂商已有渠道的官网，尝试 /pricing、/changelog 等路径，找不到再退回新闻搜索。
  - 识别后自动填好表单并运行「测试预览」，同时列出其它可选方案（如页面上的其它订阅源），你确认后再保存。

## 五点五、v2.2 AI 厂商默认全开 + 分类

- 预置厂商分为 6 类：**大模型**、**AI 智能体 / 编程助手**、**AI 创作工具**、通用软件、云与算力、实物商品（以及「自定义」）。
- 前三类（AI 相关）默认全部启用，共 30 个：OpenAI（含 Codex / ChatGPT Agent）、Anthropic（含 Claude Code）、Gemini、Microsoft Copilot、xAI、Meta AI、Mistral、Perplexity、Cursor、GitHub Copilot、DeepSeek、Kimi、智谱（含智谱清言 / AutoGLM）、通义、豆包、文心、元宝、星火、MiniMax、Midjourney、ElevenLabs、Runway、Suno，以及新增智能体厂商 **Devin（Cognition）、Manus、Coze / 扣子、Dify、LangChain、n8n、Genspark**（渠道均于 2026-10-13 实测）。
- Notion / Adobe / Canva / Figma、AWS / Google Cloud / Azure / Cloudflare 保持可选（默认关闭）。
- 老用户升级：一次性把 AI 三类预设厂商全部打开；升级后你手动关闭的厂商（开关、「停用本类」、欢迎页取消勾选）会被记住，不会再被打开。
- 欢迎页按分类显示并默认勾选全部 AI 类；「厂商与渠道」页顶部有分类标签，每类可一键「启用本类全部 / 停用本类」。
- 性能：并发默认 6 → 8；新闻搜索 / HN / App Store / YouTube 等公开 API 同站间隔缩短，队列最长的站点先抓。默认配置首次全量扫描约 209 个渠道（不含 14 个 JS 渲染渠道）约 87 秒（Reddit 匿名限流 7 秒/次是主要下限）。

## 五点六、v2.3 今日要点 / 结构化字段 / 降噪
- **今日要点（默认首页）**：统计磁贴 + 重点优惠（按重要度 × 可信度 × 新鲜度）+ 官方价格页变动 + 即将截止 + 本周活跃厂商；每条可直接 打开 / 已领取 / 忽略 / 不是优惠。
- **结构化字段**：自动抽取 力度/金额、适用对象（学生/创业/开发者…）、地区与资格（国内可用 / 可能需海外账号 / 第三方中转）、截止日期、领取方式、来源可信度。
- **处理状态**：未处理 / 已领取 / 已忽略；列表默认隐藏已忽略。
- **不是优惠 反馈**：一键标记，可选噪声关键词或屏蔽该来源；对历史数据立即生效（设置 → 提醒 中可撤销）。
- **提醒控制**：最低可信度、免打扰时段（结束后汇总推送）、每日摘要时间、立即发送摘要。
- **AI 中文翻译 + 要点**（需在设置中配置 AI Key）：英文标题自动翻成中文，原文保留在下方。
- **精度**：新规则过滤 社区提问/吐槽、负面新闻、对比测评、传闻、硬件、教程播客；实测样本精度 54% → 见 PM_REVIEW.md。
- 升级自动迁移旧数据（dealsSchema 3），收藏与已领取永不清理。

## 五点七、v2.4 厂商 logo + 多语言
- **厂商 logo**：侧边栏、卡片、表格、时间线、今日要点、厂商页、详情中都显示真实 logo。58 个预置厂商的 logo 在构建时从官网 favicon / apple-touch-icon 下载并校验，打包在 `assets/logos/`（128×128，离线可用，高分屏清晰）；自己添加或 AI 发现的厂商在添加时自动抓取官网图标并缓存在数据目录 `logos/`；加载失败自动回退为首字母头像。
- **界面语言**：简体中文 / English。首次启动跟随系统语言（中文系统 → 中文，其它 → 英文）；可在「设置 → 外观与窗口 → 界面语言」或欢迎页右上角切换，界面立即刷新、无需重启。托盘菜单、通知、每日摘要同步切换。
- **优惠内容按语言显示**：中文界面下英文优惠显示 AI 中文译文；英文界面下英文优惠显示原文、中文优惠在配置 AI 后显示英文译文。译文按语言缓存，不重复消耗；原文始终显示在下方。
- **每个预置厂商都有中英文简介**；日期 / 数字按所选语言格式化。
- 文案全部外置在 `src/locales/zh-CN.json`、`en.json`（gettext 风格：中文原文为 key），新增语言只需复制一份 json 并在 `src/renderer/i18n.js` 的 `LANGS` 中登记；`node scripts/i18n-extract.js --check` 检查缺失项和硬编码残留。

## 五点八、v2.5 精度 / 跨语言去重 / 翻译
- **精度**：过滤行业「价格战」评论、播客访谈、非 AI 购物站、试用教程、灰色「哪里最便宜」比价文；设置中可「隐藏中转转售」。配置 AI 后可选「AI 优惠分类」批量识别噪声（结果缓存，无 Key 时跳过）。
- **跨语言合并**：同一优惠的中英文报道合并为一张卡，显示「N 个来源」（按厂商 / 金额 / 时长 / 产品名锚点，宁可漏合）。
- **翻译**：提示词更稳；每轮翻译条数可调（默认 40）；已翻译条目显示「译 / EN」角标。
- **首页空状态**与截止日期强调（今天截止会闪烁提示）。

## 五点九、v2.6 能不能领、适用于我吗
- **有效期状态**：进行中 / 即将截止（3 天内）/ 已过期 / 状态未知。来源：标题与摘要里的截止日期 + 落地页定期复查（设置 →「落地页复查」，默认 12 小时）。列表默认隐藏已过期（设置 →「隐藏已过期」，或列表勾选「含已过期」/ 按有效期筛选）。
- **适用于我**：设置 →「适用于我」填写地区、学生、新 / 老用户和可用支付方式；列表勾选「只看适用于我」，可开启「只通知适用的」。信息不足的优惠默认视为适用。
- **厂商快速查询**：搜索框输入厂商名 / 别名 / 中文名（如 claude、豆包、亚马逊云科技），列表上方出现厂商卡片：未过期优惠、官方价格页、最近检查时间、渠道健康。
- **如何领取**：优惠详情里的步骤、官方领取直达链接、优惠码复制按钮，以及「可能需绑卡 / 自动续费 / 需海外账号 / 第三方中转」等提醒。
- **覆盖透明度**：左侧「覆盖透明度」页按厂商列出渠道正常 / 失败数、上次成功检查时间、失败的源和已知盲区（需登录的 X、LinkedIn、Discord，公众号，App 内活动等）。
- **v2.6.1 复查规则**：落地页 404/410 需连续两次复查确认才判「已过期」（防止网站偶发错误误伤）；只有官方页面复查正常才标「进行中」；「只看适用于我」勾选重启后保留。

## 五点十、v2.7 更聪明的引擎
- **自适应轮询**：按每个渠道的历史变化频率自动调整检查间隔，变化少的渠道少查（设置 → 智能引擎，可关闭 / 调上限）。
- **价格页**：左侧「价格」——各厂商官方价格页自动识别的套餐价格、划线原价、约合人民币、历史走势；价格变化会生成「降价 / 涨价」条目。
- **来源可靠度 / 偏好学习**：根据你的收藏、忽略等反馈在本机学习；首页「帮我判断」点 👍👎 可加快学习。不可靠来源和你大概率不感兴趣的条目不再弹通知。
- 方法来源见 RESEARCH.md。

## 五点十一、v2.8 推送 / 视图 / 分享
- **推送渠道**：左侧「推送渠道」→ 添加渠道，支持企业微信 / 飞书 / 钉钉群机器人、Telegram、Server酱（推到微信）、ntfy（推到手机）、Webhook；可「发送测试」。
- **摘要**：同一页设置每日要点、每周周报（选星期几），也会推送到勾选了摘要的渠道。
- **视图**：在优惠列表设好筛选后点工具栏的书签按钮「保存为视图」，侧栏「我的视图」点铃铛 = 有新条目时提醒。
- **分享**：详情里「分享」复制 Markdown，「分享图片」复制卡片图片，「PNG」保存图片。
- **试用到期**：标记已领取后，详情里设置到期日，提前 2 天和当天提醒。
- **上手预设**：设置 →「上手预设」。

## 五点十二、v2.9 更准、更省
- 同一事件的多篇报道自动合并（含 Google 新闻里不同媒体的同题报道）。
- 网页监控自动忽略 Cookie 横幅、「几小时前更新」、导航栏等变化；价格页只在金额 / 套餐 / 优惠字样变化时提醒。
- 多个独立网站报道的优惠可信度更高；网页缓存保存在 `httpcache.json.gz`，重启后也能省流量。

## 六、设置

- **刷新间隔**：5 分钟到 3 小时，默认 15 分钟（渠道可单独设置周期）。
- **网络代理**：默认「跟随系统」。在中国大陆访问 OpenAI、Google、Reddit 等境外站点需要代理；可一键填入常用端口（Clash 7890、Clash Verge 7897、v2rayN 10809、SOCKS5 1080），「检测网络」测试连通性。国内渠道可在渠道高级选项里设为直连。
- 其它：通知、主题、托盘、开机自启、数据保留天数、清空 / 恢复默认、实物商品监控（可选，默认关闭）。

## 七、数据存放位置

数据存放在 `%APPDATA%\全网优惠雷达\`：
- `config.json`：厂商、渠道、数据源和设置
- `httpcache.json.gz`：网页条件请求缓存（可删除，不影响数据）
- `deals.json`：优惠记录
- `pages.json`：网页变化监控 / Sitemap 的快照
- `health.json`：每个渠道最近 40 次运行记录（源健康）

卸载不会删除这个目录，如需彻底清除请手动删除。
